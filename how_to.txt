EMPIRE BOT - QUICK START
========================

Run commands from the repository root:

    cd /Users/edisonhussey/Desktop/github_gge_bot/empire_network_bot
    source venv/bin/activate

The detailed mode notes and editable attack locations are indexed at:

    bot/event/README.md


FIRST-TIME SETUP
----------------

    python -m bot.cli accounts
    python -m bot.cli db init
    python -m bot.cli db populate

Account selection normally comes from the login detected by the proxy. Check it
with `python -m bot.cli session`. An explicit `--ventrilo`, `--pingpoko`, or
`--account-name NAME` is verified against that live session.


NORMAL PROXY RUN
----------------

Terminal A:

    mitmdump -s bot/rbc_proxy_listener.py

Log into the game through proxy `127.0.0.1:8080`, then use Terminal B:

    python -m bot.cli --ventrilo proxy start --mode sands --max-attacks 200
    python -m bot.cli --ventrilo proxy start --mode storm --max-attacks 200

Status and stop:

    python -m bot.cli --ventrilo proxy status
    python -m bot.cli --ventrilo proxy end

Hands-off Berimond has its own configuration and entry point:

    # edit bot/event/berimond_kingdom/run_config.json
    python run_berimond.py


INSPECTION
----------

    python -m bot.cli tasks
    python -m bot.cli attacks --payload
    python -m bot.cli troops
    python -m bot.cli db status
